# Security and privacy checklist

- Repository visibility **PUBLIC** means all files, their names and Git history are accessible to everyone.
- Publish only educational content intended for public distribution. Never upload student records, grades, names, private course communications, university-only licensed materials, passwords, tokens or unpublished research.
- Use a separate GitHub repository from professional and commercial projects. Review PDF attachments/metadata and images before committing.
- Turn on multifactor authentication for your GitHub account; prefer hardware security keys or passkeys.
- Do not grant write access to students or untrusted outside accounts. Review repository collaborators and Actions permissions.
- This site uses only first-party HTML/CSS/JS and locally stored images and PDFs. It does not run analytics, trackers, cookies, forms, or external script dependencies.
- Students don't need accounts. Hosting service access logs may still be processed by GitHub.
- Do not enable GitHub Discussions or Issues as student assignment submission systems for confidential submissions without appropriate privacy evaluation.
- GitHub Pages makes material public; do not claim that these PDFs are private or that copies cannot be redistributed.
- QR codes are static HTTPS links to `https://ovladon.github.io/learn/#...`; anyone can inspect the full encoded URLs.
- Retain stable links to preserve printed QR codes.
