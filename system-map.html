Explore a request:
01 HUMAN Has a goal: ask a question, search, book or buy. Start with intent, not technology. LEARN ↗ #fund-00 02 DEVICE A phone or laptop turns actions into digital messages. App · keyboard · network connection LEARN ↗ #fund-01 03 INTERNET Routers move data between networks. Delay, routing and encryption matter. LEARN ↗ #fund-02 04 APPLICATION A service authenticates users and processes requests. API = Application Programming Interface. LEARN ↗ #front-05 05 DATA CENTER Servers, storage and networks provide compute capacity. Power, cooling, availability and cost. LEARN ↗ #dc-01 06 AI MODEL When needed, a model computes a response from its inputs. AI = Artificial Intelligence; it may be wrong. LEARN ↗ #front-01 07 AI AGENT An agent can plan steps and decide to call tools. Permissions, checks and stop rules matter. LEARN ↗ #front-06 08 TOOLS Software services can search, calculate or change data. A tool call may affect real systems. LEARN ↗ #front-07 09 REAL WORLD A result reaches people or changes external state. Verify the outcome, not just the text. LEARN ↗ #front-10
