# Contributions and submissions

**LEARN is a personal teaching-materials repository, not a collaborative content project.**

I, [Vlad Belciug (@ovladon)](https://github.com/ovladon), am its only publisher and maintainer. I create, select, update and teach with the materials available here.

**Outside contributions are not accepted.** Please do not submit pull requests, student assignments, uploads, edits, translations, file attachments or material donations. The website does not have an upload or submission feature.

You are welcome to **read and download** the freely available lessons for individual study, subject to [USAGE.md](USAGE.md). If you notice an error, use the communication channel already established for my class; publishing a correction remains my decision.

Public visibility on GitHub may allow forks and pull requests, but these do not alter the original `ovladon/learn` repository or published website unless someone with authorized write access acts on them.
